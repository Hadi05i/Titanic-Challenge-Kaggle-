Project Name: Titanic Survival Prediction
Overview:
This project predicts who survived the Titanic disaster using Machine Learning. I improved the model from a Decision Tree to a Random Forest Classifier to achieve better accuracy.
Methodology:
• Handled missing data for Age and Fare.
• Converted Sex to numerical values (0 and 1).
• Used Random Forest with 100 trees and a depth of 5.
Results:
• Best Score: 0.78468 (Top 25% on Kaggle)
Tools:
• Python (Pandas, Scikit-Learn)
